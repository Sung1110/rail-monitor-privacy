Privacy Policy

Application: Rail Monitor (輿情) · Last updated: June 10, 2026

This application is a personal-use, non-commercial monitoring tool operated by an individual developer. It uses the official Threads API (Meta Platforms, Inc.) to periodically search for recent public Threads posts containing railway-related keywords (e.g., Taiwan Railway, high-speed rail, train stations), and delivers matching results as notifications to the developer's own private messaging channel.

1. Information We Access

The application accesses only the following, via the official Threads API with the threads_basic and threads_keyword_search permissions:

— Public Threads posts returned by the keyword search endpoint, including post text, author username, timestamp, and permalink.
— Basic profile information of the authenticated account used by the application itself.

The application does not access private posts, direct messages, follower lists, or any non-public information. It does not collect information from any third-party users, and it has no user-facing interface — no one other than the developer uses it.

2. How Information Is Used

Search results are used for one purpose only: sending notifications about railway-related public posts to the developer's own device. The information is not used for advertising, profiling, automated decision-making, or any commercial purpose.

3. Data Storage and Retention

The application stores only minimal technical data needed to operate: post identifiers (to avoid duplicate notifications) and its own API access token. Post content is not stored in any database; it exists only transiently in delivered notification messages. No personal data of any third party is retained.

4. Data Sharing

No data is sold, rented, shared with, or disclosed to any third party. Data is transmitted only between the Threads API and the developer's private notification channel.

5. Data Deletion

To request deletion of any data associated with this application, or to revoke its access, you may:

— Remove the application's permissions in Threads: Settings → Account → Website permissions.
— Contact the developer via the GitHub repository hosting this page (open an Issue), and any stored identifiers will be deleted promptly.

6. Compliance

This application complies with the Meta Platform Terms and Threads API policies. It performs read-only keyword searches within official API rate limits and does not engage in scraping, automation of user interactions, or redistribution of content.

7. Contact

For any privacy-related questions, please open an Issue on the GitHub repository where this page is hosted.
